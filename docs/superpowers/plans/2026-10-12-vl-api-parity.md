# VL API Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the `hiv/vl/*` endpoints of `api_openldr_python` return the same numbers as the legacy Node VL API (`openldr-backend`), so the new `apps/vl` dashboard (piece 2) can replace `cargaviral.openldr.org.mz`. The only allowed differences are the documented ✱ bug fixes.

**Architecture:** One new module, `hiv/vl/services/vl_common.py`, defines every counting rule, date window and location filter once. The laboratory, facility, summary, weekly and patients services are rebuilt on top of it. `run_reporting_endpoint` starts returning real HTTP status codes and stops leaking SQL in error bodies. Tests compile each service's query with the SQL Server dialect, with no database, and assert the WHERE / GROUP BY fragments. A script, `tools/vl_parity_check.py`, compares Node and Python on real data before cutover.

**Tech Stack:** Python 3.12, Flask 3.1 + Flask-RESTful, SQLAlchemy 2.0.40 (mssql dialect), pytest. No new dependencies (`requests` is already in `requirements.txt`).

**Spec:** `openldr-monorepo/docs/superpowers/specs/2026-10-12-vl-dashboard-migration-design.md` (section 4, "Piece 1"; it lives on the monorepo branch `docs/vl-dashboard-migration-spec`).

**Legacy reference:** the Node SQL for every endpoint was generated by running the real Node controllers, and is summarised in the "Node parity rules" table below. That table is the authority for exact column names, date columns and defaults.

## Global Constraints

- Work on branch `feat/vl-api-parity`, cut from `origin/dev`. Open the PR against `dev`.
- Keep the existing Python response keys (`not_suppressed`, `requesting_facility`, `testing_facility`, `total`, ...). Add keys; never rename one. The one exception is `summary/samples_history/`, whose shape the spec redefines.

- `python -m pytest -q` passes after every task without any database or network.
- No new pip dependencies.
- Do not change TB or EID query logic. The only shared changes are `run_reporting_endpoint` error mapping (Task 2) and `PROCESS_COMMON_PARAMS_VL` date and disaggregation parsing (Task 1). EID calls the latter too, which is intended.

| facilities `rejected_samples_by_month`, `rejected_samples_by_facility` | `/clinic_samples_rejected_*` | Node: `RegisteredDateTime BETWEEN` ✱ | Requesting*, default `!= 'null'` | Node: AND of both codes ✱ |

The definitions behind the table:
- **`BETWEEN`:** `col BETWEEN 'start' AND 'end'` on bare `YYYY-MM-DD` strings, so the end day counts only rows stamped at midnight. This is Node's behaviour and is kept for parity.
- **Has result:** `ViralLoadResultCategory NOT LIKE ''`, which also drops NULLs.
- **TAT rule:** has result **and** `DATEDIFF(day, SpecimenDatetime, ReceivedDatetime) >= 0`. There is no 90-day cap, because Node's cap was lost to a duplicate object key. Averages are `AVG` of an INT, so they truncate.
- **Requesting\*:** filter on `RequestingProvinceName` / `RequestingDistrictName` / `RequestingFacilityName`, chosen by `facility_type`.
- **`!= 'null'`:** applied only when no location is given. It excludes the text `'null'` and NULL.

## Review Focus

1. **Repeated or malformed dates:** `?interval_dates=2025-01-01&interval_dates=2025-03-31` and `interval_dates=2025-13-01,2025-12-31`. Expect the right window and a 400, never a 500. Pinned in Task 1 (`test_parse_vl_params_*`) and Task 2 (`test_invalid_parameter_returns_400`).
2. **A service-side database error:** expect HTTP 500 with no SQL or driver text in the body (today the body leaks both). Pinned in Task 2 (`test_service_error_dict_*`).
3. **Lab selection combined with location:** `lab_code=PCD,PDD` plus `province=Gaza`, or neither. Expect `IN (...)` without `P%`, location without `P%`, and `P%` alone, respectively. Pinned in Task 4 (`test_tested_samples_*`).
4. **Patient rows with NULL `ReasonForTest`, phones or IDs:** expect no crash, `"Reason Not Specified"` and `None`/first non-empty values. Pinned in Task 8 (`test_process_vl_patient_*`).
5. **Week defaults on boundary days:** expect Sunday→Saturday windows whether today is a Sunday, Monday or Saturday. Pinned in Task 5 (`test_current_week_*`).

- [ ] **Step 2: Create the SQL capture helper `tests/hiv/sql_capture.py`**

```python
"""
Capture the queries a service would run, compiled for SQL Server.

Services finish their SQLAlchemy queries with ``.all()``, ``.one()`` or
``.count()``. Patching those lets a test run a real service with no
database and inspect the exact SQL it would send.
"""
from contextlib import contextmanager
from unittest.mock import MagicMock, patch

from sqlalchemy.dialects import mssql
from sqlalchemy.orm import Query


def to_sql(query):
    """Compile a Query, select or clause with literal values, on one line."""
    statement = getattr(query, "statement", query)
    compiled = statement.compile(
        dialect=mssql.dialect(), compile_kwargs={"literal_binds": True}
    )
    return " ".join(str(compiled).split())


@contextmanager
def captured_queries(results=None):
    """Record every Query that reaches ``.all()`` / ``.one()``.

    ``results`` is an optional list of return values handed out, in order,
    to successive ``.all()`` calls. Once it runs out, ``.all()`` returns [].
    ``.count()`` always returns 0.
    """
    queries = []
    pending = list(results or [])

    def fake_all(self):
        queries.append(self)
        return pending.pop(0) if pending else []

    def fake_one(self):
        queries.append(self)
        return MagicMock()

    with patch.object(Query, "all", fake_all), patch.object(
        Query, "one", fake_one
    ), patch.object(Query, "count", lambda self: 0):
        yield queries


def service_sql(app, service, req_args, results=None):
    """Run ``service`` with no database; return (result, [sql, ...])."""
    with app.app_context(), captured_queries(results) as queries:
        result = service(dict(req_args))
        sql = [to_sql(query) for query in queries]
    return result, sql
```

```python
def split_values(raw):
    """Flatten repeated and comma-separated query values into a clean list."""
    if not raw:
        return []
    if isinstance(raw, str):
        raw = [raw]
    values = []
    for item in raw:
        values.extend(part.strip() for part in str(item).split(",") if part.strip())
    return values


def parse_age_range(raw):
    """``"15,49"`` (or ``["15", "49"]``) -> ``(15, 49)``; ``None`` when absent."""
    parts = split_values(raw)
    if not parts:
        return None
    try:
        low, high = (int(part) for part in parts)
    except ValueError:
        raise InvalidParameter("age_range must be two whole numbers: min,max") from None
    if low < 0 or high < low:
        raise InvalidParameter("age_range must satisfy 0 <= min <= max")
    return low, high


def _validated_dates(raw):
    dates = coerce_interval_dates(raw)
    for value in dates:
        try:
            date.fromisoformat(value)
        except ValueError:
            raise InvalidParameter(
                "interval_dates must be two YYYY-MM-DD dates: start,end"
            ) from None
    return dates


def parse_vl_params(req_args):
    """Normalise the query parameters shared by every VL reporting endpoint."""
    facility_type = req_args.get("facility_type") or "province"
    health_facility = req_args.get("health_facility")

    if facility_type == "province":
        facilities = req_args.get("province") or []
    elif facility_type == "district":
        facilities = req_args.get("district") or []
    elif facility_type == "health_facility" and health_facility:
        facilities = [health_facility]
    else:
        facilities = []

    return VlParams(
        dates=_validated_dates(req_args.get("interval_dates")),
        facilities=[f.strip() for f in facilities if f and f.strip()],

        in TRUTHY_VALUES,
        health_facility=health_facility,

    The end day only counts rows stamped exactly at midnight. This matches

    """``CAST(column AS DATE)`` between start and end, both days whole."""

    return and_(day >= dates[0], day <= dates[1])
```

```python
def service_result_response(result):
    """
    Turn a service's error dict into a real HTTP status.

    Services return ``{"status": "error", "code": N, ...}`` on failure. 4xx
    bodies are returned as they are. For 5xx the exception text (``error``)
    is logged and dropped, and the message is replaced with a generic one,
    so SQL and driver details never reach the caller.
    """
    if not (isinstance(result, dict) and result.get("status") == "error"):
        return result

    code = result.get("code")
    if not isinstance(code, int) or not 400 <= code <= 599:
        code = 500

    if result.get("error"):
        logger.error("Service error on %s: %s", request.path, result["error"])

    body = {key: value for key, value in result.items() if key != "error"}
    body["code"] = code
    if code >= 500:
        body["message"] = GENERIC_SERVER_ERROR
    return body, code


def run_reporting_endpoint(parse_fn, service_fn):
    """
    Execute the standard pipeline shared by every reporting endpoint.

    1. Authenticate the request and populate the session.
    2. Parse the request arguments via ``parse_fn``.
    3. Inject ``user_id`` into the parsed arguments.
    4. Invoke ``service_fn(req_args)``.
    5. Map the outcome to an HTTP response: ``InvalidParameter`` -> 400,
       service error dicts -> their own status, anything unexpected -> a
       generic 500 (details are logged, never returned).
    """
    user_id, err = authenticate_request()
    if err is not None:
        return err

    try:
        req_args = parse_fn()
        req_args["user_id"] = user_id
        result = service_fn(req_args)
    except HTTPException:
        raise
    except InvalidParameter as exc:
        return {"status": "error", "code": 400, "message": str(exc)}, 400
    except Exception:
        logger.exception("Unhandled error on %s", request.path)
        return {"status": "error", "code": 500, "message": GENERIC_SERVER_ERROR}, 500

    return service_result_response(result)
```

```python
HIV VL summary (Sumário) services.

Each function matches one legacy Node dashboard endpoint (named in its
docstring); the counting rules come from hiv/vl/services/vl_common.py.

from pathlib import Path

from sqlalchemy import and_, func

from hiv.vl.models.vl import VlData
from hiv.vl.services.vl_common import (
    date_between,

def _error(e):
    return {"status": "error", "code": 500, "message": "An Error Occurred", "error": str(e)}


def _monthly(query, month_cols):
    return query.group_by(*month_cols).order_by(month_cols[0], month_cols[1]).all()


# ---------------------------------------------------------------------------
# 1. header_indicators_service_by_month
# ---------------------------------------------------------------------------
def header_indicators_service_by_month(req_args):
    """Single-row totals: registered, tested, suppressed, not_suppressed, rejected."""
    params = parse_vl_params(req_args)
    filters = [
        date_between(VlData.RegisteredDateTime, params.dates),
        *testing_location_filters(params),
    ]
    try:
        row = (
            VlData.query.with_entities(
                func.count().label("registered"),
                tested_count(),
                suppressed_count(),
                not_suppressed_count(),
                rejected_count(),
            )
            .filter(and_(*filters))
            .one()
        )
        return dict(
            registered=row.registered,
            tested=row.tested,
            suppressed=row.suppressed,
            not_suppressed=row.not_suppressed,
            rejected=row.rejected,
            facilities=params.facilities,
            start_date=params.dates[0],
            end_date=params.dates[1],
        )
    except Exception as e:
        return _error(e)


# ---------------------------------------------------------------------------
# 2. number_of_samples_service_by_month   (legacy /dash_number_of_samples)
# ---------------------------------------------------------------------------
def number_of_samples_service_by_month(req_args):
    """Samples analysed per month (every row with an AnalysisDateTime in range)."""
    params = parse_vl_params(req_args)
    month_cols = year_month_columns(VlData.AnalysisDateTime)
    filters = [
        date_between(VlData.AnalysisDateTime, params.dates),
        *testing_location_filters(params),
    ]
    try:
        data = _monthly(
            VlData.query.with_entities(*month_cols, TOTAL_ALL).filter(and_(*filters)),
            month_cols,
        )
        return [
            dict(
                year=row.year, month=row.month, month_name=row.month_name,
                total=row.total,
                start_date=params.dates[0], end_date=params.dates[1],
                facilities=params.facilities,
            )
            for row in data
        ]
    except Exception as e:
        return _error(e)

    params = parse_vl_params(req_args)
    filters = [
        date_between(VlData.AnalysisDateTime, params.dates),
        has_result(),
        *requesting_location_filters(params, exclude_null_province=False),

            .group_by(VlData.RequestingProvinceName)

                suppressed=row.suppressed,
                not_suppressed=row.not_suppressed,
                routine=row.routine,

                start_date=params.dates[0], end_date=params.dates[1],
                facilities=params.facilities,

        ]

        return _error(e)
```

```python
def lab_names(codes):
    """Map lab codes to their dictionary LabName, skipping blank names."""
    wanted = sorted({code.strip() for code in codes if code and code.strip()})
    if not wanted:
        return {}
    rows = (
        Laboratories.query.with_entities(Laboratories.LabCode, Laboratories.LabName)
        .filter(
            Laboratories.LabCode.in_(wanted),
            Laboratories.LabName.is_not(None),
            Laboratories.LabName != "",
        )
        .all()
    )
    return {row.LabCode.strip(): row.LabName.strip() for row in rows}
```

```python
"""
Weekly VL lab reports read from ReportData.Resume (legacy /lab_weekly_report
and /lab_weekly_report_national).

The window filters on the week's start_date, both ends inclusive. Without
interval_dates, the per-lab report shows the current Sunday-Saturday week and
the national report the last 12 weeks, as in Node.
"""
from datetime import date, datetime, timedelta

from sqlalchemy import func

from db.database import db
from hiv.vl.models.report_data import Resume
from hiv.vl.services.vl_common import date_between_inclusive, parse_vl_params
from utilities.service_helpers import InvalidParameter


def _today():
    return date.today()


def current_week(today):
    """Sunday..Saturday of the week containing ``today``."""
    start = today - timedelta(days=(today.weekday() + 1) % 7)
    return [start.isoformat(), (start + timedelta(days=6)).isoformat()]


def last_12_weeks(today):
    return [(today - timedelta(weeks=12)).isoformat(), today.isoformat()]


def _day(value):
    if isinstance(value, datetime):
        return value.date().isoformat()
    return value.isoformat() if value is not None else None


def _resume_rows(req_args, by_lab, default_window):
    params = parse_vl_params(req_args)
    dates = params.dates if req_args.get("interval_dates") else default_window(_today())

    keys = [Resume.week, Resume.start_date, Resume.end_date]
    if by_lab:
        keys = [Resume.labcode, Resume.labname, *keys]

    filters = [date_between_inclusive(Resume.start_date, dates)]
    if params.lab_codes:
        filters.append(Resume.labcode.in_(params.lab_codes))

    return (
        db.session.query(
            *keys,
            func.sum(Resume.backlogs).label("backlogs"),
            func.sum(Resume.tests).label("tests"),
            func.sum(Resume.registered).label("registrations"),
            func.sum(Resume.rejected).label("rejections"),
            func.sum(Resume.capacity).label("capacity"),
            func.avg(Resume.tat).label("tat"),
        )
        .filter(*filters)
        .group_by(*keys)
        .order_by(Resume.start_date)
        .all()
    )


def _figures(row):
    return dict(
        week=row.week,
        start=_day(row.start_date),
        end=_day(row.end_date),
        backlogs=row.backlogs,
        tests=row.tests,
        registrations=row.registrations,
        rejections=row.rejections,
        capacity=row.capacity,
        tat=float(row.tat) if row.tat is not None else None,
    )


def _error(e):
    return {"status": "error", "code": 500, "message": "An Error Occurred", "error": str(e)}


def weekly_report_service(req_args):
    """One row per lab and week."""
    try:
        rows = _resume_rows(req_args, by_lab=True, default_window=current_week)
    except InvalidParameter:
        raise
    except Exception as e:
        return _error(e)
    return [dict(lab_code=row.labcode, lab_name=row.labname, **_figures(row)) for row in rows]


def weekly_report_national_service(req_args):
    """One row per week (tat is the unweighted mean of the lab TATs, as in Node)."""
    try:
        rows = _resume_rows(req_args, by_lab=False, default_window=last_12_weeks)
    except InvalidParameter:
        raise
    except Exception as e:
        return _error(e)
    return [_figures(row) for row in rows]
```

```python
def paginate_query(query, page, per_page):
    """Return (rows, total_count, total_pages) for a 1-indexed page."""
    query = query.order_by(VlData.RequestID)
    total_count = query.count()
    total_pages = ceil(total_count / per_page) if per_page > 0 else 0
    rows = query.offset((page - 1) * per_page).limit(per_page).all()
    return rows, total_count, total_pages


def _paging(req_args):
    raw_page, raw_per_page = req_args.get("page"), req_args.get("per_page")
    try:
        page = 1 if raw_page in (None, "") else int(raw_page)
        per_page = 50 if raw_per_page in (None, "") else int(raw_per_page)
    except (TypeError, ValueError):
        raise InvalidParameter("page and per_page must be whole numbers") from None
    if page < 1 or per_page < 1:
        raise InvalidParameter("page and per_page must be at least 1")
    return page, min(per_page, MAX_PER_PAGE)


def _truthy(value):
    return str(value or "").strip().lower() in TRUTHY_VALUES


def _clean(values):
    return [value.strip() for value in (values or []) if value and value.strip()]


def _result_values(raw):
    values = []
    for item in split_values(raw):
        key = item.lower()
        if key not in RESULT_TYPES:
            raise InvalidParameter(
                f"Invalid 'result_type' value: '{item}'. Valid values: suppressed, not_suppressed."
            )
        values.append(RESULT_TYPES[key])
    return values


def _test_reason_values(raw):
    values = []
    for item in split_values(raw):
        if item not in TEST_REASONS:
            raise InvalidParameter(
                f"Invalid 'test_reason' value: '{item}'. Valid values: {', '.join(TEST_REASONS)}."
            )
        values.extend(TEST_REASONS[item])
    return values


def _drill_down_filters(req_args, params):
    """Optional filters shared by every search (the card drill-downs)."""
    filters = []
    provinces = _clean(req_args.get("province"))
    districts = _clean(req_args.get("district"))
    if provinces:
        filters.append(VlData.RequestingProvinceName.in_(provinces))
    if districts:
        filters.append(VlData.RequestingDistrictName.in_(districts))
    if params.health_facility:
        filters.append(VlData.RequestingFacilityName == params.health_facility)
    if params.lab_codes:
        filters.append(VlData.TestingFacilityCode.in_(params.lab_codes))
    filters.extend(age_range_filters(params))
    if _truthy(req_args.get("pregnant")):

    if _truthy(req_args.get("breastfeeding")):
        filters.append(breastfeeding_filter())
    if _truthy(req_args.get("rejected")):

    result_values = _result_values(req_args.get("result_type"))
    if result_values:
        filters.append(VlData.ViralLoadResultCategory.in_(result_values))
    return filters


def _admin_only(req_args):
    user_id, user_role = _get_user_role(req_args)
    return _check_admin_access(user_id, user_role)


def _bad_request(message):
    return {"status": "error", "code": 400, "message": message}


def _search(req_args, params, date_column, filters):
    page, per_page = _paging(req_args)
    filters = [
        date_between(date_column, params.dates),
        *filters,
        *_drill_down_filters(req_args, params),

    try:
        query = VlData.query.with_entities(*VL_PATIENT_ENTITIES).filter(*filters)
        rows, total_count, total_pages = paginate_query(query, page, per_page)

            "total_count": total_count,
            "total_pages": total_pages,
```

```python
def default_windows(year):
    return {
        "12 months": (f"{year}-01-01", f"{year}-12-31"),

def node_query(start, end, extra):
    """Node expects qs 'indices' arrays: dates[0]=..&codes[1]=.."""
    params = [("dates[0]", start), ("dates[1]", end)]
    for name, value in extra.items():
        if isinstance(value, list):
            params.extend((f"{name}[{i}]", item) for i, item in enumerate(value))
        else:
            params.append((name, value))
    return params


def python_query(start, end, extra):
    return [("interval_dates", f"{start},{end}"), *extra.items()]


def _key_value(field, value):
    if field == "start" and isinstance(value, str):
        return value[:10]
    if isinstance(value, str):
        return value.strip()
    return value


def index_rows(rows, key_fields, value_fields, aggregate=False):
    """{key tuple: {field: value}}; with aggregate, rows sharing a key are summed."""
    index = {}
    for row in rows:
        key = tuple(_key_value(field, row.get(field)) for field in key_fields)
        values = {field: row.get(field) for field in value_fields}
        if aggregate and key in index:
            for field, value in values.items():
                index[key][field] = (index[key][field] or 0) + (value or 0)
        else:
            index[key] = values
    return index


def _same(a, b):
    if isinstance(a, (int, float)) and isinstance(b, (int, float)):
        return abs(a - b) <= FLOAT_TOLERANCE
    return a == b


def compare(node_index, python_index, field_pairs):
    differences = []
    for key in sorted(set(node_index) | set(python_index), key=repr):
        if key not in python_index:
            differences.append(f"{key} missing in python")
            continue
        if key not in node_index:
            differences.append(f"{key} missing in node")
            continue
        for node_field, python_field in field_pairs:
            node_value = node_index[key].get(node_field)
            python_value = python_index[key].get(python_field)
            if not _same(node_value, python_value):
                differences.append(f"{key} {node_field}: node={node_value} python={python_value}")
    return differences


def run_check(check, window, fetch, node_base, python_base, headers):
    start, end = window
    node_rows = fetch(node_base, check.node_path, node_query(start, end, check.node_params), {})
    python_rows = fetch(python_base, check.python_path, python_query(start, end, check.python_params), headers)
    node_fields = [pair[0] for pair in check.fields]
    python_fields = [pair[1] for pair in check.fields]
    differences = compare(
        index_rows(node_rows, check.node_keys, node_fields, aggregate=False),
        index_rows(python_rows, check.python_keys, python_fields, aggregate=check.aggregate),
        check.fields,
    )
    if not differences:
        return "OK", []
    return ("EXPECTED ✱" if check.expected else "DIFF"), differences

                status, differences = run_check(check, window, fetch, args.node, args.python, headers)
            except requests.RequestException as exc:
                status, differences = "ERROR", [str(exc)]
            print(f"{status:11} {check.node_path} -> {check.python_path}")
            if check.expected and differences:
                print(f"            {check.expected}")
            for line in differences[:5]:
                print(f"            {line}")
            if len(differences) > 5:
                print(f"            ... {len(differences) - 5} more")
            if status in ("DIFF", "ERROR"):
                unexpected += 1
    for path, reason in SKIPPED.items():
        print(f"SKIPPED     {path}: {reason}")
    print(f"\n{unexpected} check(s) with unexpected differences")
    return 1 if unexpected else 0


if __name__ == "__main__":
    sys.exit(main())
```
