# EID Master schema (2026-10)

## Column source

Columns are taken from the legacy Sequelize model `openldr-api/src/.../EIDMaster` (file copied to `.superpowers/sdd/2026-10-26-eid-api/legacy-EIDMaster.ts`), at commit `90bc2f8` on `origin/main` of openldr-api. That model was fixed for the rebuilt table and confirmed against production on 2026-10-19. The model has no `ID` column (`removeAttribute("id")`), so `RequestID` is mapped as the SQLAlchemy primary key (mapper-only; no DDL is issued).

Type mapping: STRING to String, DATEONLY/DATE to DateTime, FLOAT to Float, INTEGER to Integer, BOOLEAN to Boolean.
