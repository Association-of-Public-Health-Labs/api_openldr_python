# EID Master schema (2026-10)

## Column source

Columns are taken from the legacy Sequelize model `openldr-api/src/.../EIDMaster` (file copied to `.superpowers/sdd/2026-10-26-eid-api/legacy-EIDMaster.ts`), at commit `90bc2f8` on `origin/main` of openldr-api. That model was fixed for the rebuilt table and confirmed against production on 2026-10-19. The model has no `ID` column (`removeAttribute("id")`), so `RequestID` is mapped as the SQLAlchemy primary key (mapper-only; no DDL is issued).

Type mapping: STRING to String, DATEONLY/DATE to DateTime, FLOAT to Float, INTEGER to Integer, BOOLEAN to Boolean.

SELECT FinalResult, COUNT(*) n FROM EIDMaster GROUP BY FinalResult ORDER BY n DESC;
SELECT IsPoc, LIMSAnalyzerCode, COUNT(*) n FROM EIDMaster GROUP BY IsPoc, LIMSAnalyzerCode ORDER BY n DESC;

### Mapping used by `hiv/eid/services/eid_common.py`

Provisional (2026-10-26), pending user confirmation; each list is one constant (`RESULT_VALUES`, `PENDING_RESULT_VALUES`, `EQUIPMENT_GROUPS`).

- **positive**: `Positivo`, `Reactive`, `DTS`
- **negative**: `Negativo`, `Not Reactive`, `Not Detected DBS`, `NDET`
- **indeterminate**: `INCONCLUSIVE`, `Indeterminado`, `Inconclusive*`
- **pending**: not rejected AND (`FinalResult` NULL or `''` OR `FinalResult IN ('NDT', 'Nível de detecção baixo')`)
- **no class**: `INS`, `INST`, `Insufficient sample`, `Repeat Test` (counted in none of the above)
- **Rejection codes** outside the 8 legacy buckets (`COM`, `INLS`, `FDR`, `AMONR`, `HAEM`, `15DIA`, `NOCD`, `OUTR`, `SAALC`) are counted in `other`. A row rejected only by description (empty code) is in the rejected total but in no reason column (legacy).
- **Analyzer codes** are compared after `LTRIM(RTRIM(...))`. Codes added to the legacy groups: `C680A` (C6800), `M200C` (M2000), `PNTHC` (PANTHER), `ALNTB` (ALINITY).
